    Silver SQL 論点潰しテキスト¶

    ORACLE MASTER Silver SQL（1Z0-071）の問題を 「判定基準」で解く ためのテキストです。

    教科書のように最初から通読するものではありません。 問題を解いて間違えたら、その論点のページを開いて「なぜそうなるか」を確認する ための辞書として使ってください。

    このテキストの考え方¶

    試験問題の多くは、次のような形をしています。

    • 「正常に実行される問合せはどれですか」
    • 「構文エラーにならずに実行されるコマンドはどれですか」
    • 「何行返されますか」「どのような結果が返されますか」
    • 「〜したいと思います。どの問合せを使用しますか」
    • 「〜について正しい記述はどれですか」

    こうした問題は、選択肢を1つずつ 「正しい構文・正しい動作の条件」 に照らし合わせれば判定できます。 このテキストは各論点を、次の形でまとめています。

    ルール（判定基準） … 正しい構文・動作が満たす条件 → 条件を満たさないものはエラー／誤り

    ✅ OK例 / ❌ NG例 … 条件に照らした具体例（理由つき）

    ひっかけ … 試験で狙われやすい勘違い

    記号の意味

    • ✅ … 正常に実行される／正しい
    • ❌ … エラーになる／誤り
    • ⚠️ … エラーにはならないが、期待した結果にならない（「エラーになる」と誤答しやすい）

    使い方¶

    1. 問題を解く（Ping-t・問題集など）
    2. 間違えた・迷った問題の 問題タイプ を 問題タイプ別の解き方 で探す
    3. そこからリンクされている 論点 を読み、判定基準を確認する
    4. 章末の ○×クイック判定 で、同じ論点の言い換えにも対応できるか確認する

    検索も使えます

    画面上部の検索ボックスに NULLIF、WITH GRANT OPTION、ORA-00979 のようなキーワードを入れると該当箇所に飛べます。

    第1章 RDBとOracleの基礎 SQLの特徴、E-Rモデル（多対多の分解）、キーとNULL、SQL*PlusとSQL Developer

    第4章 単一行関数 文字関数（SUBSTR/INSTR/TRIM/REPLACE…）、数値関数（ROUND/TRUNC/MOD）、日付演算と日付関数
    第5章 変換関数・NULL関数・条件式 暗黙の型変換、TO_CHAR/TO_DATE/TO_NUMBER、RR書式、NVL/NVL2/NULLIF/COALESCE、CASE/DECODE
    第6章 集計関数とGROUP BY 集計関数とNULL、COUNTの3形態、GROUP BYのルール、HAVING、集計関数のネスト
    第7章 結合 ON/USING/NATURAL JOINの制約、外部結合、自己結合、非等価結合、クロス結合の行数
    第8章 副問合せ 単一行と複数行、ANY/ALL、NOT INとNULL、相関副問合せ、EXISTS、副問合せが必要な場面
    第9章 集合演算 列数・データ型の一致、列名、ORDER BYの位置、重複排除とソート、行数の数え方
    第10章 DMLとトランザクション INSERT/UPDATE/DELETE、マルチテーブルINSERT、MERGE、コミット／ロールバックの契機、SAVEPOINT
    第11章 索引・シーケンス・シノニム 索引の自動作成、UNUSABLE/INVISIBLE、シーケンスの定義と使える場所、シノニムの名前空間
    第12章 DDLによる表の管理 命名規則、DEFAULT、制約の書き方、ALTER TABLEの可否、DROP/TRUNCATE、CTAS、一時表、外部表
    第13章 ビュー CREATE OR REPLACE/FORCE、ALTER VIEW、DMLできないビュー、WITH CHECK OPTION
    第14章 ユーザー・権限・ロール システム権限とオブジェクト権限、GRANT構文の可否、ADMIN/GRANT OPTIONの取消し、権限の要否
    第15章 データディクショナリ USER_/ALL_/DBA_、DICTIONARY、実表の扱い
    第16章 タイムゾーンと期間 日時型の違い、現在日時関数、INTERVAL型とリテラル

    • 試験の前提となる Oracle Database 19c 相当の仕様で書いています。
