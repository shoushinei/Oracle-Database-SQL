    第4章 単一行関数¶

    この章で問われる形

    • 「単一行ファンクションに関して正しい記述はどれですか」
    • 「次の問合せを実行すると、どのような結果が返されますか」（TRIM・REPLACE・SUBSTR などのネスト）
    • 「大文字／小文字を問わず○○を含む行を抽出したい。どの問合せですか」
    • 「入社日が過去nか月以内の行を表示したい。どのWHERE句ですか」
    • 「SYSDATEに関して正しい記述はどれですか」

    4-1 単一行関数の性質¶

    判定基準

    1. 1行ごとに 処理し、1行につき1つ の値を返す
    2. 引数には 列名・リテラル・式 を指定できる
    3. 引数の数は関数による（0個：SYSDATE、1個：UPPER、複数：SUBSTR、ROUND…）
    4. 戻り値の型は 引数の型と一致するとは限らない（例：LENGTH('abc') は数値を返す）
    5. SELECT・WHERE・ORDER BY（HAVING・GROUP BY、INSERTのVALUES、UPDATEのSET）など さまざまな場所 で使える
    6. 何重にもネストできる（内側から評価）
    選択肢の言い回し 判定
    引数には列名、リテラル、または式を指定できる ✅
    すべての単一行ファンクションは1つの引数のみ受け付ける ❌
    SELECT文のFROM句でのみ使用できる ❌
    戻り値のデータ型は引数のデータ型と常に一致する ❌
    単一行ファンクションは複数の行をまとめて1つの値を返す ❌（それは集計関数）
    ネストは2レベルまで ❌（単一行関数は制限なし。2レベルまでは 集計関数）

    4-2 大文字・小文字の変換（UPPER / LOWER / INITCAP）¶

    判定基準

    関数 結果
    UPPER('Oracle.com') ORACLE.COM
    LOWER('Oracle.com') oracle.com
    INITCAP('oracle.COM') Oracle.Com（単語ごとに先頭だけ大文字、残りは小文字）
    • INITCAPの「単語」の区切りは 英数字以外の文字（空白・.・@・_ など）

    「大文字小文字を問わず ○○ を含む」の判定¶

    両辺の大小を揃えているか を見ます。

    WHERE UPPER(email) LIKE '%ORACLE%'              -- ✅ 列を大文字化して大文字で比較
WHERE UPPER(email) LIKE UPPER('%oracle%')       -- ✅ 両辺を大文字化
WHERE LOWER(email) LIKE '%oracle%'              -- ✅ 両辺小文字
WHERE email LIKE '%oracle%'                     -- ⚠️ 小文字の oracle しかヒットしない
WHERE UPPER(email) LIKE '%oracle%'              -- ⚠️ 大文字化した値に小文字パターン → 0行
WHERE INITCAP(email) LIKE '%ORACLE%'            -- ⚠️ INITCAPは "Oracle" になるので一致しない

    4-3 SUBSTR / INSTR / LENGTH¶

    判定基準

    関数 働き ポイント
    SUBSTR(文字列, 開始 [, 文字数]) 部分文字列 開始は 1から。負なら末尾から数える。文字数省略で 最後まで
    INSTR(文字列, 探す文字 [, 開始 [, n回目]]) 位置（数値） 見つからなければ 0。開始が負なら末尾から逆向きに探す
    LENGTH(文字列) 文字数（数値） NULLならNULL 
    SUBSTR('ABCDEFG', 3)          -- 'CDEFG'
SUBSTR('ABCDEFG', 3, 2)       -- 'CD'
SUBSTR('ABCDEFG', -3)         -- 'EFG'（後ろから3文字目から最後まで）
SUBSTR('ABCDEFG', -3, 2)      -- 'EF'
INSTR('A@B@C', '@')           -- 2
INSTR('A@B@C', '@', 1, 2)     -- 4（2回目）
INSTR('ABC', 'X')             -- 0
LENGTH('Oracle')              -- 6

    「@より後ろ（ドメイン部分）」の取り出し方

    SUBSTR(email, INSTR(email, '@') + 1)
    INSTRで @ の位置を求め、その 次の文字（+1）から最後まで を取り出します。

    4-4 TRIM / LTRIM / RTRIM / REPLACE / LPAD / RPAD¶

    判定基準：TRIM

    TRIM( [ LEADING | TRAILING | BOTH ] [ 削除する1文字 ] FROM 文字列 )
    1. LEADING＝先頭、TRAILING＝末尾、BOTH＝両端（省略時はBOTH）
    2. 削除する文字は 1文字だけ 指定できる（2文字以上は ❌ ORA-30001）。省略時は空白
    3. 端から 連続している限り何個でも 削除する（途中の文字は削除しない）

    判定基準：その他

    関数 働き
    LTRIM(文字列 [, 文字の集合]) / RTRIM(...) 左／右端から、集合に含まれる文字を削除（複数文字の集合を指定可）
    REPLACE(文字列, 探す文字列 [, 置換後]) すべての 一致箇所を置換。置換後を省略すると 削除
    LPAD(文字列, 長さ, 埋める文字) / RPAD 左／右を埋めて指定の長さに。元が長ければ切り詰める 
    TRIM('  ab c  ')                         -- 'ab c'（途中の空白は残る）
TRIM(LEADING '0' FROM '00120')           -- '120'
TRIM(TRAILING '#' FROM '#A#B##')         -- '#A#B'（末尾の連続した # だけ削除）
TRIM('#' FROM '#A#B##')                  -- 'A#B'（両端）
TRIM('AB' FROM 'ABCAB')                  -- ❌ 削除文字は1文字だけ
RTRIM('xyzABCyx', 'xyz')                 -- 'xyzABC'（右端から x,y,z のどれかを削除）
REPLACE('A-B-C', '-', '+')               -- 'A+B+C'
REPLACE('A-B-C', '-')                    -- 'ABC'
LPAD('123', 6, '*')                      -- '***123'
LPAD('ABCDEFG', 3, '*')                  -- 'ABC'（切り詰め）

    4-5 CONCAT¶

    判定基準

    1. CONCAT(文字列1, 文字列2) … 引数はちょうど2つ（3つ以上は ❌ ORA-00909）
    2. 3つ以上つなぐなら ネスト するか || を使う
    3. NULLは || と同様に無視される
    CONCAT(first_name, last_name)                    -- ✅
CONCAT(first_name, ' ', last_name)               -- ❌ 引数3つ
CONCAT(CONCAT(first_name, ' '), last_name)       -- ✅ ネスト
first_name || ' ' || last_name                   -- ✅

    4-6 数値関数（ROUND / TRUNC / MOD / POWER …）¶

    判定基準

    関数 働き ポイント
    ROUND(n [, d]) 四捨五入 d省略=0。d が負なら整数部を丸める
    TRUNC(n [, d]) 切り捨て 同上
    MOD(m, n) m を n で割った余り 符号は m と同じ。MOD(m, 0) は m（エラーにならない）
    POWER(m, n) m の n 乗 積ではない
    CEIL(n) n 以上 の最小の整数
    FLOOR(n) n 以下 の最大の整数
    ABS(n) 絶対値
    • ROUND と TRUNC は DATE型も引数に取れる（→ 4-9）
    ROUND(45.926, 2)    -- 45.93
ROUND(45.926)       -- 46
ROUND(45.926, -1)   -- 50
ROUND(1234.5, -2)   -- 1200
TRUNC(45.926, 2)    -- 45.92
TRUNC(45.926, -1)   -- 40
MOD(10, 3)          -- 1
MOD(-10, 3)         -- -1
MOD(10, 0)          -- 10
POWER(2, 3)         -- 8
CEIL(2.1)           -- 3
FLOOR(-2.1)         -- -3

    4-7 日付の算術演算¶

    判定基準

    式 結果の型 意味
    日付 + 数値 日付 n日後
    日付 − 数値 日付 n日前
    日付 + 数値/24 日付 n時間後
    日付 − 日付 数値 日数（時刻の差は小数で表れる）
    日付 + 日付 ❌ ORA-00975
    日付 * 数値、日付 / 数値 ❌ 型の不一致
    数値 − 日付 ❌

    SYSDATE¶

    1. データベースサーバーのOS の現在日時を返す（クライアントの時刻ではない）
    2. 戻り値は DATE型。時刻も含む（表示されるかは NLS_DATE_FORMAT 次第）
    3. 1つの文の中では 同じ値（全行で同じ時刻）
    4. SYSDATE + 1 は ちょうど24時間後（翌日の同時刻）
    選択肢の言い回し 判定
    SELECT sysdate*2 FROM dual はエラーにならずに結果が返る ❌
    SELECT sysdate FROM employees はエラーになる ❌（行数分返る）
    SELECT sysdate+1 FROM dual はDBサーバーOSの現在日時の24時間後を返す ✅
    SELECT sysdate FROM dual は年月日を返すが時刻は返さない ❌（時刻も持つ）

    4-8 日付関数（MONTHS_BETWEEN / ADD_MONTHS …）¶

    判定基準

    関数 働き ポイント
    MONTHS_BETWEEN(d1, d2) d1 − d2 の 月数 d1が新しければ正。小数も出る。引数の順番が重要
    ADD_MONTHS(d, n) nか月後の日付 nが負なら前。月末は調整（1/31の1か月後→2月末）
    NEXT_DAY(d, '曜日') d より後 の、指定曜日の日付 曜日名は NLS_DATE_LANGUAGE に従う
    LAST_DAY(d) その月の 末日
    EXTRACT(YEAR FROM d) 年・月・日などを数値で取り出す

    「入社日が過去60か月以内」の判定¶

    WHERE MONTHS_BETWEEN(SYSDATE, hire_date) <= 60     -- ✅ (今 − 入社日) が60か月以下
WHERE ADD_MONTHS(hire_date, 60) >= SYSDATE         -- ✅ 入社日の60か月後がまだ来ていない
WHERE MONTHS_BETWEEN(hire_date, SYSDATE) <= 60     -- ⚠️ 引数が逆。常に負になり過去の全員がヒット
WHERE ADD_MONTHS(hire_date, 60) <= SYSDATE         -- ⚠️ 逆に「60か月より前に入社」
WHERE SYSDATE - hire_date <= 60                    -- ⚠️ 60「日」以内

    コツ

    MONTHS_BETWEEN は「新しい方を先」に書くと正の値になります。比較の向きと符号をセットで確認しましょう。

    4-9 日付の ROUND / TRUNC¶

    判定基準

    書き方 結果
    TRUNC(d) その日の 00:00:00
    TRUNC(d, 'MONTH') その月の 1日
    TRUNC(d, 'YEAR') その年の 1月1日
    ROUND(d) 正午以降 なら翌日、前なら当日（の00:00）
    ROUND(d, 'MONTH') 16日以降 なら翌月1日、15日までなら当月1日
    ROUND(d, 'YEAR') 7月1日以降 なら翌年1月1日、6月までなら当年1月1日 
    ROUND(DATE '2024-07-16', 'MONTH')   -- 2024-08-01
TRUNC(DATE '2024-07-16', 'MONTH')   -- 2024-07-01
ROUND(DATE '2024-07-16', 'YEAR')    -- 2025-01-01
TRUNC(DATE '2024-07-16', 'YEAR')    -- 2024-01-01

    4-10 関数のネストと評価順¶

    判定基準

    1. いちばん内側から 順に評価する
    2. 各段階の 戻り値（型も） を書き出してから次の関数に渡す
    3. 単一行関数のネストの深さに制限はない
    SELECT UPPER(REPLACE(TRIM(TRAILING '*' FROM 'ab*c**'), 'b', 'x')) FROM dual;
    段階 処理 結果
    1 TRIM(TRAILING '*' FROM 'ab*c**') 'ab*c'（末尾の ** だけ削除）
    2 REPLACE('ab*c', 'b', 'x') 'ax*c'
    3 UPPER('ax*c') 'AX*C'

    結果を選ぶ問題の解き方

    選択肢を見比べると、どの段階を間違えた答えか が分かることが多いです。 「途中の文字も削除した答え」「片端だけ／両端を削除した答え」「置換し忘れた答え」が並んでいるので、1段ずつ確定させます。

    ○×クイック判定¶

    記述 判定 ひとこと
    単一行関数の引数には列名・リテラル・式を指定できる ✅
    すべての単一行関数は引数を1つだけとる ❌ 0個〜複数
    単一行関数の戻り値の型は引数の型と常に一致する ❌
    TRUNCは引数にDATEをとれる ✅
    ROUNDは引数にNUMBERのみとれる ❌ DATEも可
    POWERは積を返す ❌ べき乗
    MODは除算の余りを返す ✅
    MOD(m, 0) はエラーになる ❌ m を返す
    CONCATは3つ以上の引数をとれる ❌ 2つだけ
    TRIMで削除する文字は複数指定できる ❌ 1文字
    TRIMは文字列の途中の文字も削除する ❌ 両端のみ
    REPLACEの第3引数を省略すると該当文字列が削除される ✅
    SUBSTRの開始位置に負の値を指定すると末尾から数える ✅
    INSTRで見つからないときはNULLを返す ❌ 0
    日付 − 日付 の結果は日数（数値） ✅
    日付 + 日付 は可能 ❌
    SYSDATEはクライアントの日時を返す ❌ DBサーバーOS
    MONTHS_BETWEEN(d1,d2) は d1 が新しいと正の値 ✅
