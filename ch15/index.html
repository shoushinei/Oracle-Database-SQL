    第15章 データディクショナリ¶

    この章で問われる形

    • 「データディクショナリに関して正しい記述はどれですか（2つ選択）」
    • 「○○を確認するにはどのビューを参照しますか」

    15-1 データディクショナリとは¶

    判定基準

    1. データベースの メタデータ（表・列・制約・ユーザー・権限などの定義情報）を格納した表とビューの集まり
    2. 実表（ベース表）は SYS ユーザーが所有 し、SYSTEM 表領域 に格納されている
    3. 実表は Oracle Server が自動的に更新 する（DDLを実行すると反映される）
    4. ユーザー（DBAを含む）が実表を 直接変更してはいけない（DELETE・UPDATE などは厳禁）
    5. ユーザーは ビュー（データディクショナリビュー）を通して参照 する。ビューは 読取り専用
    6. 定期的なリビルドなどの メンテナンスは不要
    選択肢の言い回し 判定
    Oracle Server は、実行する DDL に応じてデータディクショナリを自動的に更新している ✅
    データディクショナリの実表は SYSTEM 表領域に格納されている ✅
    DBA はオブジェクトを削除するとき、実表から直接 DELETE してもよい ❌
    DBA は定期的にデータディクショナリをリビルドする必要がある ❌
    SYS ユーザーはすべてのデータディクショナリへのアクセス権限を持っている ✅

    15-2 ビューの接頭辞¶

    判定基準

    接頭辞 見える範囲 誰が参照できるか
    USER_ 自分が所有する オブジェクト（OWNER列がない） 全ユーザー
    ALL_ 自分が アクセス権限を持つ オブジェクト（自分の所有＋権限を受けたもの） 全ユーザー
    DBA_ データベース内の すべて のオブジェクト DBA など権限を持つユーザー
    V$ 動的パフォーマンスビュー（メモリ・稼働状況） 権限を持つユーザー
    • 見える範囲の大きさ：USER_ ⊂ ALL_ ⊂ DBA_
    • DICTIONARY（シノニム DICT）… データディクショナリビューの 名前と説明の一覧
    選択肢の言い回し 判定
    USER_ ビューは、所有かどうかに関係なく、アクセス権限を持つすべてのオブジェクトを表示する ❌（それは ALL_）
    ALL_ と DBA_ で始まるビューは、DBAのみが参照できる ❌（ALL_ は全ユーザー）
    ビューの名前と簡単な説明の一覧を見たいときは DICTIONARY ビューを参照する ✅

    15-3 主なデータディクショナリビュー¶

    知りたいこと ビュー
    ディクショナリビューの一覧 DICTIONARY（DICT）
    自分のオブジェクトの一覧（種類・状態・作成日） USER_OBJECTS
    自分の表 USER_TABLES（TABS）
    表の列（型・NULL可否・デフォルト値） USER_TAB_COLUMNS（COLS）
    制約（種類 P/U/R/C、条件、状態） USER_CONSTRAINTS
    制約がどの列に付いているか USER_CONS_COLUMNS
    索引 USER_INDEXES
    索引の列 USER_IND_COLUMNS
    ビューの定義（SELECT文） USER_VIEWS（TEXT列）
    シーケンス（次に発番される値の目安） USER_SEQUENCES（LAST_NUMBER列）
    シノニム USER_SYNONYMS
    未使用列がある表 USER_UNUSED_COL_TABS
    ごみ箱 USER_RECYCLEBIN（RECYCLEBIN）
    自分に付与されたシステム権限／ロール USER_SYS_PRIVS / USER_ROLE_PRIVS
    オブジェクト権限 USER_TAB_PRIVS（列単位は USER_COL_PRIVS）
    現在のセッションで有効な権限 SESSION_PRIVS
    表・列のコメント USER_TAB_COMMENTS / USER_COL_COMMENTS

    制約の種類コード（USER_CONSTRAINTS.CONSTRAINT_TYPE）

    P 主キー、U 一意キー、R 外部キー（参照）、C CHECK（NOT NULL も C）

    コメントの付け方¶

    COMMENT ON TABLE employees IS '社員マスタ';
COMMENT ON COLUMN employees.salary IS '月給';

    COMMENT は DDL（暗黙コミットされる）。削除するときは空文字 '' を設定します。

    ○×クイック判定¶

    記述 判定 ひとこと
    データディクショナリの実表はSYSが所有する ✅
    実表はSYSTEM表領域にある ✅
    DDLを実行するとデータディクショナリは自動更新される ✅
    DBAは実表を直接更新してよい ❌
    データディクショナリは定期的にリビルドする ❌
    USER_ビューにはOWNER列がある ❌ 自分のものだけなので不要
    USER_ビューにはアクセス権限のある全オブジェクトが出る ❌ ALL_
    ALL_ビューはDBAしか参照できない ❌ 全ユーザー
    DBA_ビューはデータベース内のすべてのオブジェクトを表示する ✅
    DICTIONARYビューでディクショナリビューの一覧を確認できる ✅
    NOT NULL制約のCONSTRAINT_TYPEは 'N' ❌ 'C'
