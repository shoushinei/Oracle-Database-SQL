# Silver SQL 論点潰しテキスト

ORACLE MASTER Silver SQL（1Z0-071）の問題を **「判定基準」で解く** ためのテキストです。

教科書のように最初から通読するものではありません。
**問題を解いて間違えたら、その論点のページを開いて「なぜそうなるか」を確認する** ための辞書として使ってください。

---

## このテキストの考え方

試験問題の多くは、次のような形をしています。

- 「**正常に実行される**問合せはどれですか」
- 「**構文エラーにならず**に実行されるコマンドはどれですか」
- 「**何行**返されますか」「どのような**結果**が返されますか」
- 「〜したいと思います。**どの問合せを使用しますか**」
- 「〜について**正しい記述**はどれですか」

こうした問題は、選択肢を1つずつ **「正しい構文・正しい動作の条件」** に照らし合わせれば判定できます。
このテキストは各論点を、次の形でまとめています。

<div class="rule-box" markdown>

**ルール（判定基準）** … 正しい構文・動作が満たす条件
→ 条件を満たさないものはエラー／誤り

**✅ OK例 / ❌ NG例** … 条件に照らした具体例（理由つき）

**ひっかけ** … 試験で狙われやすい勘違い

</div>

!!! tip "記号の意味"
    - ✅ … 正常に実行される／正しい
    - ❌ … エラーになる／誤り
    - ⚠️ … エラーにはならないが、期待した結果にならない（「エラーになる」と誤答しやすい）

---

## 使い方

1. 問題を解く（Ping-t・問題集など）
2. 間違えた・迷った問題の **問題タイプ** を [問題タイプ別の解き方](howto.md) で探す
3. そこからリンクされている **論点** を読み、判定基準を確認する
4. 章末の **○×クイック判定** で、同じ論点の言い換えにも対応できるか確認する

!!! info "検索も使えます"
    画面上部の検索ボックスに `NULLIF`、`WITH GRANT OPTION`、`ORA-00979` のようなキーワードを入れると該当箇所に飛べます。
